Como saber se o cliente viu a proposta

Mandar a proposta e ficar no escuro é um dos maiores motivos de vendas perdidas. Saber se o cliente abriu muda a forma de fazer o follow-up.

Por que o PDF no WhatsApp não mostra isso

Quando você envia um arquivo, só sabe que a mensagem foi entregue ou lida. Não sabe se o cliente abriu o documento, quantas vezes voltou nele ou se mostrou para outra pessoa.

A alternativa: proposta por link

Quando a proposta é uma página acessada por link, o sistema consegue registrar cada abertura. Assim você vê o status (enviada, visualizada, aprovada) e o histórico de acessos.

Como usar essa informação

  • Abriu logo depois do envio: o interesse está alto. Pergunte se ficou alguma dúvida.
  • Abriu várias vezes: o cliente está comparando ou mostrando para alguém. É uma boa hora para oferecer uma conversa rápida.
  • Não abriu depois de alguns dias: talvez a mensagem tenha se perdido. Reenvie o link com uma frase curta.

Exemplo de mensagem de follow-up

Oi, [nome]! Vi que você deu uma olhada na proposta.
Ficou alguma dúvida sobre o escopo ou a forma de pagamento?
Se quiser, te explico em 5 minutos por aqui.

Perguntas frequentes

Dá para saber se o cliente abriu um PDF enviado no WhatsApp?

Não. O WhatsApp mostra que a mensagem foi lida, mas não registra a abertura do arquivo. Com proposta por link, cada acesso fica registrado.

Quando fazer follow-up de uma proposta?

Um bom momento é logo depois que o cliente abre a proposta, enquanto o assunto está fresco.
